Veltrix Rendering Engine

A custom HTML rendering engine built from the ground up.

This document tests HTML parsing, CSS selectors, text layout, font rendering, inline formatting and smooth scrolling.

1. Introduction

Veltrix is an experimental browser rendering engine designed to understand HTML documents and transform them into visual content through a custom rendering pipeline.

The engine processes HTML using a parser, constructs a document tree, calculates styles, creates layout structures and finally produces a display list that is rendered through SDL.

Important: HTML is not simply a collection of strings. It represents a structured document containing elements, attributes, nested content and relationships.

4. Long Paragraph Testing

A rendering engine must correctly calculate the dimensions of every element and determine where content should appear within the viewport. Text wrapping is particularly important because a paragraph may contain hundreds or thousands of characters. The layout system must identify available width, calculate glyph advances, account for whitespace and determine when a new line should begin.

When inline elements are nested inside paragraphs, the engine must preserve their formatting while maintaining the correct position of every character. A bold word should not cause the following text to overlap. A smaller font should not create unexpected gaps. Whitespace between adjacent elements should remain consistent.

Scrolling introduces another important requirement. The document can be much taller than the visible window. The rendering engine must preserve document coordinates while translating visible content according to the current scroll position. Elements outside the viewport should not needlessly consume rendering resources.
